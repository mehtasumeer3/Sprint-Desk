# SprintDesk Screen Recording Script
Aim for 3–5 minutes.

1. **Intro (15s):** Show repo and explain stack/architecture briefly.
2. **Authentication (30s):** Login, show protected navigation, refresh to demonstrate session recovery.
3. **Board (90s):** Cross-column drag, reorder, refresh persistence, create task, edit in drawer, add comment, delete with confirmation, show filters and undo.
4. **Analytics (45s):** Show the four responsive charts and explain they derive from current board state.
5. **Notifications + theme (30s):** Open bell, mark read/all read, mention 15s visibility-aware polling; toggle dark mode.
6. **Responsive + accessibility (30s):** Show 375px viewport and keyboard focus/drag support.
7. **Engineering quality (30s):** Show `docs/ARCHITECTURE.md`, `docs/API.md`, README limitations, then run `npm run test`.
